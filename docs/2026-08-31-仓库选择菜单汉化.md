# 仓库选择菜单汉化

## 目标

把 Cursor 仓库选择菜单（Repos）里仍显示英文的条目译成中文，避免「本机 / 云端 / 从零开始」等选项继续显示原文。

## 做了什么

在 `FanYi_CiDian` 中新增仓库选择器及相关子菜单映射，并加强省略号/`+` 前缀匹配。同时修复桌面「Cursor中文」快捷方式：1.2.0 把本机 `QiDong_Cursor_ZhongWen.vbs` 删掉后，快捷方式指向了不存在的文件。

| 英文 | 中文 |
|------|------|
| Repos / Recents | 仓库 / 最近 |
| On This PC / This PC | 本机 |
| Cloud | 云端 |
| Start from scratch | 从零开始 |
| Use Existing... | 使用已有... |
| New Folder | 新建文件夹 |
| Add Workspace | 添加工作区 |
| Clone Repository | 克隆仓库 |
| Connect via SSH / WSL | 通过 SSH / WSL 连接 |

## 改了哪些文件

- `CursorHanHua_GongJu.py`：增加仓库选择器汉化条目

## 怎么验证

1. 运行 `python CursorHanHua_GongJu.py` 重新注入
2. 完全退出并重启 Cursor
3. 打开仓库选择菜单，确认上述条目已显示中文

## 风险/未完成

- `Cloud` 为精确匹配，其他如 `Cloud Agents` 仍走原有更长条目，互不影响
- 若 Cursor 后续改文案（大小写、省略号、措辞），需再补词典
- 未改用量条位置与刷新逻辑
