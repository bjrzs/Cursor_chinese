# 修复中文快捷方式并补全仓库菜单

## 目标

排查桌面「Cursor中文」无法启动，以及仓库选择菜单仍显示英文的问题。

## 做了什么

1. **快捷方式失效**：快捷方式指向 `QiDong_Cursor_ZhongWen.vbs`，该文件在 1.2.0 起改为 example 且被 gitignore，本机文件缺失导致 `wscript` 启动失败。安装/自愈时会重新生成本机 VBS。
2. **菜单汉化不全**：补全「使用已有」子菜单（添加工作区、克隆仓库、SSH/WSL 等）及搜索框占位符；翻译匹配兼容 `…` 与 `+` 前缀。
3. 重新安装桌面快捷方式并重新注入本机 Cursor。

## 改了哪些文件

- `CursorHanHua_GongJu.py`：词典、匹配逻辑、缺失时重写 VBS
- 本机生成（不入库）：`QiDong_Cursor_ZhongWen.vbs`、桌面 `Cursor中文.lnk`

## 怎么验证

1. 双击桌面「Cursor中文」，应能无黑框启动 Cursor
2. 完全退出后用该快捷方式启动，打开仓库菜单
3. 确认本机/云端/从零开始/使用已有，以及子菜单「添加工作区」「克隆仓库」「通过 SSH 连接」等为中文

## 风险/未完成

- GitHub / GitLab / Azure DevOps 保留英文品牌名
- 若 Cursor 用封闭 Shadow DOM 渲染部分菜单，仍可能漏译
- 必须完全退出旧 Cursor 进程后再开，否则会继续用内存里的旧脚本
