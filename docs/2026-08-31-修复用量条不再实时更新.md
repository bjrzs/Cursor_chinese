# 修复用量条不再实时更新

## 目标

查明聊天输入框下方用量百分比停住不涨的原因，并恢复运行中自动刷新。

## 做了什么

根因有两处：

1. **后台监控进程没在跑**。`--qi-dong` 启动监控时若 Cursor 尚未出现在进程列表，监控会立刻退出；之后普通打开 Cursor 也不会再拉起监控。`usage_live.json` 停在当天上午注入时的快照。
2. **页面 60 秒轮询把过期 live json 当成成功**，不再请求官网。浏览器里也无法带 Cookie 访问 `cursor.com`，所以点击刷新同样拿不到新数据。

修复：

- 监控先等待 Cursor 启动，进程短暂消失也不立即退出
- 注入/自愈时若 Cursor 已在运行则自动拉起监控
- 监控周期只写 `usage_live.json`，不再每分钟重写整份汉化 JS
- 页面改为约 20 秒读一次 live json，并继续尝试刷新

## 改了哪些文件

- `CursorHanHua_GongJu.py`

## 怎么验证

1. 运行 `python CursorHanHua_GongJu.py` 后确认 `usage_live.json` 的 `gengXinShiJian` 为当前时间
2. 确认存在 `usage_watch.pid`，且有 `pythonw` 进程
3. 完全退出后用桌面「Cursor中文」启动，用量条应在约 20 秒内跟着官网变化
4. 点一下用量条应能刷新（依赖 live json 已被监控更新）

## 风险/未完成

- 页面直连官网仍会受跨域/Cookie 限制，实时数据以 Python 监控写 live json 为准
- 必须用「Cursor中文」启动，或至少在 Cursor 运行时执行一次注入/自愈，监控才会起来
